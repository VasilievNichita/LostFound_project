# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

Приложение для потерянных и найденных вещей в кампусе. Можно будет оставить объявление с фотографией и местом, отправить заявку на свою вещь и договориться о возврате в переписке.

Начата L2: добавлен Flutter-проект и первый вариант доски с тремя объявлениями. Пока данные находятся прямо в коде, вместо фотографий используются иконки. Карточки ещё не открываются, поиска и фильтров пока нет.

Для запуска нужны Flutter и Android-устройство или эмулятор. Из папки проекта:

```sh
flutter pub get
flutter run
```

Проверка кода: `flutter analyze` и `flutter test`.

Следующим шагом добавить отдельный экран вещи. Бэкенд будет на Python с FastAPI и SQLite, к нему вернуться на L5.
