# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

Приложение для потерянных и найденных вещей в кампусе. Можно будет оставить объявление с фотографией и местом, отправить заявку на свою вещь и договориться о возврате в переписке.

L2 завершена: добавлены восемь статических экранов Material 3. Из стартового меню можно открыть вход, доску, карточку вещи, форму объявления, заявку, переписку, свои объявления и профиль. Данные вынесены в lib/data/mock_data.dart, общие виджеты находятся в lib/widgets.

Поиск, фильтры, отправка сообщений и сохранение форм пока показаны только в интерфейсе. Вход не выполняет авторизацию. Вместо фотографий используются локальные иконки. Навигацию между рабочими экранами и валидацию добавлю на L3.

Для запуска нужны Flutter и Android-устройство или эмулятор. Из папки проекта:

```sh
flutter pub get
flutter run
```

На моем ноутбуке среда находится в D:\PAM. Перед командами Flutter в PowerShell подключаю `. D:\PAM\scripts\env.ps1`. Эмулятор запускается через `D:\PAM\scripts\start_emulator.ps1`, приложение через `D:\PAM\scripts\run_lostfound.ps1`.

Проверка кода: `flutter analyze` и `flutter test`. В L2 проходят 28 тестов, включая прокрутку всех экранов на трех размерах и проверку связей данных. Android APK собирается командой `flutter build apk --debug`.
