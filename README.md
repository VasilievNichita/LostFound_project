# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

Приложение для потерянных и найденных вещей в кампусе. Объявление связано с заявками владельцев, а каждая заявка имеет свою переписку.

В L4 формы начали менять данные. Можно добавить и отредактировать объявление, отметить возврат вещи, удалить свою публикацию, оставить заявку и написать сообщение. Доска ищет по названию и описанию, переключает потерянные и найденные вещи и фильтрует по месту. Счётчики и остальные экраны обновляются через Provider.

Данные хранятся в памяти через Repository. После полного перезапуска восстанавливается исходный набор. Вход пока проверяет только формат полей. Настоящая авторизация, сервер и фотографии относятся к L5, кэш на диске к L6.

Для запуска из папки проекта:

```powershell
flutter pub get
flutter run
```

На моём ноутбуке перед командами подключаю `. D:\PAM\scripts\env.ps1`, чтобы SDK и кэши оставались на D:. Основной проект находится в D:\PAM\LostFound_project.

Проверки: `flutter analyze`, `flutter test`, `flutter build apk --debug`. В профиле есть переключатель сбоя: включить его, вернуться на доску и нажать обновление. Появится ошибка с кнопкой повтора. После отключения сбоя повторная загрузка вернёт данные.
