# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

Приложение для потерянных и найденных вещей в кампусе. Можно открыть объявление, оставить заявку на свою вещь и перейти к переписке.

После статических экранов L2 добавлена L3: навигация go_router, постоянные вкладки «Доска», «Мои», «Профиль», проверка входа и регистрации, формы объявления и заявки. Карточки открываются по ID. Вкладки сохраняют свою прокрутку и открытые экраны. Перед выходом появляется подтверждение.

Пока это учебный режим. Вход принимает любую почту и пароль, которые проходят проверку формы. Объявления, заявки и сообщения ещё не сохраняются, сервер не подключён. Поиск и фильтры появятся на L4, фотографии и настоящая авторизация на L5.

Для запуска нужны Flutter и Android-устройство или эмулятор. Из папки проекта:

```sh
flutter pub get
flutter run
```

На моём ноутбуке перед командами подключаю `. D:\PAM\scripts\env.ps1`, чтобы SDK и кэши оставались на D:. Основной проект находится в D:\PAM\LostFound_project.

Проверка: `flutter analyze`, `flutter test`, `flutter build apk --debug`. Сценарий проверки на Android и описание адресов находятся в [заметках L3](docs/lab3.md).
