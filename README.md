# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

Приложение для потерянных и найденных вещей в кампусе. Если кто-то забыл рюкзак, ключи или другую вещь, можно будет оставить объявление с фотографией и местом. Тот, кто узнал свою вещь, сможет отправить заявку и договориться о возврате в переписке. После возврата объявление закрывается.

Приложение будет на Flutter и Dart. Для бэкенда выбран Python с FastAPI и SQLite, за основу пойдёт шаблон из материалов курса.

Пока здесь описание проекта и заметки по бэкенду. Следующий шаг — добавить Flutter-проект с темой Material 3, затем заняться доской объявлений.

План по лабораторным записан в [roadmap](docs/roadmap.md), заметки по шаблону — в [backend-template](docs/backend-template.md).
