# LostFound

Vasiliev Nichita, CR-232. Проект по PAM, тема 19.

LostFound помогает вернуть вещи, потерянные в кампусе. Можно опубликовать объявление, приложить фотографию, оставить заявку с приметами и договориться о встрече в переписке. После передачи автор отмечает вещь возвращённой.

Клиент написан на Flutter и Dart. Состояние хранится в Provider, экраны работают через Repository. В L5 подключён Python/FastAPI и SQLite. Основа сервера взята из выданного учебного шаблона; таблицы и правила LostFound добавлены в отдельных модулях. Исходные auth, notes, files и health сохранены.

Вход и регистрация обращаются к серверу. На устройстве сохраняется JWT, пароль не сохраняется. После перезапуска приложение восстанавливает вход, а при ответе 401 очищает токен. Доска получает страницы по 20 записей, поиск и фильтры выполняются на сервере. Фото отправляется через POST /files. Без сервера показывается ошибка с повтором; офлайн-кэш пока не реализован.

На моём ноутбуке проект лежит в D:\PAM\LostFound_project. Для запуска есть D:\PAM\Запустить L5.cmd. Скрипт поднимает сервер и открывает приложение на Android. База и фотографии сохраняются в D:\PAM\data\L5. Для защиты предыдущей работы используется отдельная копия D:\PAM\demo\L4 и файл D:\PAM\Запустить L4.cmd.

На другом компьютере сначала установите зависимости Python из server/requirements.txt и запустите `python -m app.main` из server. Затем из корня проекта выполните `flutter pub get` и `flutter run`. На Android-эмуляторе адрес API по умолчанию http://10.0.2.2:8080. Для телефона или другого устройства передайте адрес ноутбука: `flutter run --dart-define=API_URL=http://АДРЕС:8080`.

Проверки клиента: `flutter analyze` и `flutter test`. Проверки работающего сервера: `python server/tests/check_base.py` и `python server/tests/check_lostfound.py`. Официальные conformance и openapi.yaml в выданном архиве отсутствуют, поэтому прохождение учебного набора 37/37 не заявляется.

Демонстрационные аккаунты создаются отдельно командой `python server/tests/seed_demo.py`. Почта student@example.org или library@example.org, пароль campus123. Это тестовые данные для локальной защиты.

Подробности запуска и защиты находятся в [заметках L5](docs/lab5.md). Предыдущие отчёты сохранены в reports. L5 завершает разработку по полученной методичке; L6 посвящена итоговой презентации.
