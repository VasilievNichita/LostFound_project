# L3 в LostFound

L3 продолжает интерфейс L2 в том же репозитории. Вместо временного меню используется вход и три раздела: доска, мои объявления и заявки, профиль. Каждый раздел хранит свой стек через StatefulShellRoute.indexedStack. При переключении сохраняется прокрутка и открытая карточка.

Карта находится в lib/router.dart. /login и /register открываются без нижней панели. Внутри доски /items/new ведёт к созданию объявления, /items/:id к вещи, /items/:id/edit к редактированию своего объявления, /items/:id/claim к заявке. После проверки заявки /items/:id/preview показывает пустую учебную переписку для этой вещи. Существующие mock-заявки открываются из /activity по адресу /activity/claims/:claimId/messages. /profile показывает профиль. Неизвестные ID обрабатываются без падения.

Карточки и формы открываются через push, после формы объявления выполняется pop. Проверенная заявка заменяет свою форму через pushReplacement, поэтому назад можно вернуться к вещи. Вход и выход используют go: старый раздел исчезает из стека. Переключением вкладок управляет goBranch. Объекты через extra не передаются.

Почта проверяется на формат, пароль должен содержать минимум 6 символов. Для регистрации дополнительно нужны имя и совпадающий повтор пароля. У объявления обязательны тип, название и место. Для заявки нужно описать примету вещи от 10 до 600 символов. Пустое сообщение не отправляется. Все контроллеры освобождаются в dispose.

Данные остаются mock. Хорошая форма показывает SnackBar, но не создаёт аккаунт, объявление, заявку или сообщение на сервере. В диалоге выхода можно остаться, подтвердить выход или закрыть диалог. Поиск, фильтры и общие изменения данных относятся к L4, сервер и фотографии к L5.

Проверки находятся в test, сценарий на Android в integration_test/lab3_test.dart. Запуск сценария: flutter drive --driver=test_driver/integration_test.dart --target=integration_test/lab3_test.dart -d emulator-5554. Снимки по умолчанию сохраняются в build/lab3-screenshots; каталог можно изменить переменной LOSTFOUND_SCREENSHOTS.

Основа интерфейса взята из собственной предыдущей L2. Учебная методичка L3 задаёт требования к навигации и формам; её пример с пластинками в проект не перенесён. Используются стандартные API Flutter и пакет go_router из pub.dev. Особенности LostFound: связи вещи и заявки, отдельные переписки, проверка приметы вещи и доступ к редактированию своих mock-объявлений.
