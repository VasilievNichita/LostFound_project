# Запуск для защиты

L5 и финальная защита используют одну версию LostFound. На этом ноутбуке откройте D:\PAM\Запустить L5.cmd или D:\PAM\Запустить финальный проект.cmd. Подождите загрузки Android. Скрипт запускает API на порту 8080, устанавливает готовый APK и открывает приложение. Сборка Gradle при этом не выполняется.

Для входа в демонстрационную базу: student@example.org, пароль campus123. Второй участник: library@example.org с тем же учебным паролем. Можно зарегистрировать собственный аккаунт приложения. Пароль от университетской почты не нужен.

На защите покажите вход, поиск и фильтр места, карточку вещи, создание объявления с фото, заявку с доказательством, переписку и закрытие объявления. После перезапуска сервера записи остаются в SQLite. Переписка доступна только участникам заявки. Для двух сторон используйте выход из аккаунта и вход под вторым пользователем.

Код находится в D:\PAM\LostFound_project. В Android Studio открывайте корень проекта, не только папку android. Для структуры покажите lib/models/lost_found_model.dart, lib/data/http_repositories.dart и server/app. Презентация лежит в D:\PAM\output\LostFound_final.pptx.

Если сервер не отвечает, в PowerShell выполните: & D:\PAM\scripts\backend.ps1 -Action Restart. Проверка сервера: http://127.0.0.1:8080/health. Не удаляйте D:\PAM\data\L5: там база, фотографии и секрет JWT.

Для разработки сначала выполните . D:\PAM\scripts\env.ps1. Этот файл выбирает Java из D:\PAM\tools\android-studio\jbr, Flutter и Android SDK на D:. Затем перейдите в D:\PAM\LostFound_project и выполните flutter run -d emulator-5554. Для обычной демонстрации эта команда не нужна.

При проверке 22.11.2026 обычная сборка остановилась из-за DNS для dl.google.com при запросе Maven-зависимостей. Если зависимости уже есть в локальном кэше, сборку можно запустить из android командой .\gradlew.bat --offline assembleDebug. На другом компьютере сначала нужны доступ к репозиториям и загрузка зависимостей. Предупреждения о deprecated Kotlin/Gradle не равны ошибке сборки.

Адрес API Android-эмулятора: http://10.0.2.2:8080. Для физического телефона требуется адрес ноутбука в локальной сети и пересборка с --dart-define=API_URL=http://АДРЕС:8080. Готовый APK предназначен для эмулятора.

GitHub содержит исходники и материалы защиты. Сервер пока запускается локально, публичного облачного сервера нет. Официальный conformance-набор не был предоставлен. Offline-кэш, уведомления и карта кампуса не реализованы. По уточнённому расписанию L6 является итоговой презентацией.
