# L5 Интеграция с backend

Сервер использует FastAPI и SQLite из учебного Python-шаблона. Файлы auth.py, notes.py, files.py и errors.py сохранены. Доменные модули items.py, claims.py, messages.py, campus.py и topic_helpers.py описывают предметную область LostFound. Дополнения db.py создают таблицы со связями и каскадным удалением. Индекс не допускает две открытые заявки одного пользователя на одну вещь.

Доска общая для вошедших пользователей. Создание получает userId из JWT. Изменение и удаление вещи доступны автору. Заявку и переписку видят заявитель и автор вещи; посторонний получает 404. Удалять сообщение может отправитель, заявку может её автор. После возврата вещи новые заявки и сообщения блокируются.

GET /items возвращает items, total, page, limit. Поддержаны type, location, search и mine=1. GET /claims поддерживает itemId; GET /messages поддерживает claimId. Все списки имеют пагинацию. POST /items, POST /claims, POST /messages создают записи, PUT /items/{id} и PUT /claims/{id} меняют их, DELETE удаляет соответствующие записи. GET /campus отдаёт профиль текущего пользователя, открытые имена авторов и справочник мест. Исходные auth, notes, files, me и health продолжают работать.

В Flutter ApiClient добавляет Bearer, разбирает конверт ошибки и переводит стабильный code. Transport/timeout, HTTP status и некорректный JSON обработаны раздельно. Пустой ответ 204 не декодируется. Поток 401 стирает токен и через callback корня возвращает вход; старый ответ с предыдущим токеном не завершает новую сессию. Root заменяет модель при смене пользователя, поэтому данные прежнего аккаунта не остаются в интерфейсе.

При первоначальной подмене Repository модель и шесть экранов данных остались побайтно одинаковыми с L4. Это зафиксировано в repository-swap-evidence.json. Следующим изменением добавлены параметры страницы, серверный поиск, загрузка фото и обновление переписки. Поэтому итоговый diff этих файлов не пуст. Это отдельные изменения функциональности, а не необходимость переписывать экраны для HTTP.

Поиск отправляется через 350 мс после ввода. Ответ старого запроса не заменяет новый. Следующая страница догружается у конца списка или кнопкой «Показать ещё». При ошибке список сохраняется, повтор запрашивает ту же страницу. Своё объявление и вещи из заявок дополнительно загружаются для раздела «Мои», даже если их нет на первой странице текущего фильтра.

Фото выбирается из галереи. Клиент ограничивает размер 5 МБ, сервер также проверяет лимит. multipart send и чтение ответа имеют общий таймаут 20 секунд. К объявлению привязывается относительный imageUrl. Сервер разрешает прикрепить только свой загруженный файл с image MIME.

Для запуска на этом ноутбуке: D:\PAM\Запустить L5.cmd. Отдельное управление сервером: `& D:\PAM\scripts\backend.ps1 -Action Stop`, затем `-Action Start`. Команда `-Action Rotate` меняет локальный ключ JWT и перезапускает сервер: при следующем запросе приложение вернётся на вход. База при этих действиях не удаляется. Команда `-Action Restart` сохраняет ключ и сессии.

Для проверки сохранения входа закройте приложение через список последних приложений или force-stop и откройте снова. Для сетевой ошибки остановите сервер и нажмите обновление доски. После старта сервера нажмите «Повторить». Для переписки войдите вторым аккаунтом на другом устройстве или выйдите и смените аккаунт; сообщения обновляются кнопкой в заголовке переписки.

Демонстрационные данные добавляются только seed_demo.py, сервер их сам не создаёт. Учебные аккаунты student@example.org и library@example.org используют пароль campus123. Их нельзя применять в публичном развёртывании. Локальный HTTP разрешён Android Manifest для лабораторного стенда.

check_base.py проверяет 18 исходных операций, check_lostfound.py проверяет 36 правил LostFound. Это собственные проверки. В архиве нет conformance и openapi.yaml; официальный результат 37/37 подтвердить невозможно. Для повторения Android-интеграции запустите server/tests/integration_host.py, затем flutter drive с integration_test/lab5_test.dart и API_URL=http://10.0.2.2:8081. Тестовый стенд использует отдельную БД и порты 8081/8082, останавливает только свой дочерний сервер и не затрагивает демонстрационную базу.
