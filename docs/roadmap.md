# Ход проекта

L2: восемь статических экранов Material 3. L3: маршруты go_router, формы и валидация. L4: общее состояние Provider и mock Repository; сохранённая версия запускается отдельно от дальнейшей разработки.

L5: интеграция с собственными модулями LostFound поверх выданного Python backend. Регистрация, JWT, объявления, приватные заявки и сообщения, пагинация, поиск и фотографии. Данные сохраняются в SQLite на ноутбуке.

По уточнённому расписанию курса L6 является итоговой презентацией проекта. Отдельная разработка офлайн-кэша в текущем задании L5 не предусмотрена. Карта кампуса, уведомления и автоархивация остаются необязательными идеями.

Локально подготовленные этапы публикуются только по отдельной команде. Даты коммитов соответствуют фактическому запуску публикации, опубликованная история не переписывается.
