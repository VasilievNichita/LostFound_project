# Заметки по бэкенду

В архиве из материалов курса есть несколько вариантов сервера. Для проекта выбран Python: в нём используются FastAPI и SQLite, уже есть регистрация, вход по JWT и загрузка файлов. Node-вариант тоже есть, но он написан на JavaScript, а не на TypeScript.

В Python-шаблоне запуск и подключение маршрутов находятся в app/main.py, авторизация — в app/auth.py, база — в app/db.py. В app/notes.py сделан пример работы с заметками: создание, чтение, изменение и удаление, поиск и пагинация. По нему можно будет сделать объявления LostFound. Загрузка файлов находится в app/files.py, лимит одного файла — 5 МБ.

Для LostFound нужны три сущности: Item для объявления, Claim для заявки владельца и Message для сообщения. У объявления будут тип lost/found, название, описание, фото и место. Ещё нужны дата создания и статус, чтобы показывать дату в карточке и закрывать объявление после возврата.

Маршруты будут /items, /claims и /messages. Для сообщений нужен отбор по claimId, чтобы у каждой заявки была своя переписка. Автора запроса нужно определять по JWT. Менять объявление сможет его автор, а читать переписку — автор объявления и заявитель. Фото будут загружаться через POST /files, адрес файла сохранится в imageUrl.

По README шаблон запускается на порту 8080. Настройки PORT и JWT_SECRET задаются через переменные окружения, база app.db и папка uploads создаются в каталоге бэкенда. Перед публикацией сервера нужно заменить учебный JWT-секрет и настроить CORS.

Сервер пока не запускался. В README шаблона есть ссылки на общий openapi.yaml и проверки conformance, но этих файлов в приложенном архиве нет. К запуску и проверке API вернуться на L5; сейчас ближайшая задача — интерфейс Flutter.
