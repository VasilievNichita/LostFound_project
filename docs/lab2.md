# Лабораторная работа 2

Тема 19, LostFound. Основная рабочая папка: D:\PAM\LostFound_project. Этот же проект будет продолжен на L3-L6.

Первоначальная доска из трех объявлений сохранена в коммите ea4f04d. Затем в этот репозиторий по этапам перенесены ранее подготовленные локальные макеты L2. Это перенос существующей работы, а не повторное создание с нуля. Для каждого из восьми экранов есть отдельный коммит. Автор новых коммитов: VasilievNichita <lognip@mail.ru>. Использованы фактические даты переноса, опубликованная история не переписывалась.

В lib/screens находятся меню демонстрации и восемь обязательных экранов. В lib/data/mock_data.dart заданы 16 вещей, 8 заявок и 8 сообщений. ItemCard, ItemVisual, StatusBadge и InfoRow переиспользуются на нескольких экранах. Цвета берутся из общей темы Material 3.

Все экраны являются StatelessWidget. Действия форм, авторизация, поиск и фильтры пока статические. Реальная навигация между доской, вещью, заявкой и сообщениями, а также валидация относятся к L3. Состояние и Repository будут на L4, сервер на L5.

Проверки: flutter analyze без ошибок, flutter test с 28 успешными тестами, flutter build apk --debug. Каждый экран проверяется при 320 x 640, 412 x 915 и 360 x 800 логических пикселях; последний вариант с масштабом текста 1.3. Тесты прокручивают списки и проверяют переходы из меню.
